# 网页舞台 UI 设计图需求（给 GPT 出图用）

> 配合 `docs/WEB-STAGE-DESIGN.md` 第三节。先出图，主人选定后再照图实现。
> 设计图只是视觉参考：布局、配色、字体、组件形状。实现时数据和文字以引擎为准。

## 总体要求

- **产品**：AI 小屋的桌游观战网页。几位 AI 少女（室友）在玩剧本杀，真人在手机上观战。
- **气质**：暖色纸张感、安静、像在书房里看一场推理剧；精致，但不花哨。
- **主色**：米白纸色背景、深棕文字、琥珀色点缀；深色主题是深咖啡底、暖白字。
- **字体**：中文界面。标题用衬线体，正文用无衬线体，幕文本用衬线体排版。
- **画幅**：先出手机竖屏（390×844），再出桌面宽屏（1440×900）。
- **头像**：用圆形占位头像加座位色描边，不要画具体人物。
- **不要**：赛博朋克、霓虹、游戏 UI 那种厚重边框、密密麻麻的数据面板。

## 要出的图（每张手机一版，第 2、4 张另出桌面一版）

1. **剧本封面**：剧本名《灯塔之夜》、一句简介、人数，下面是 4 张角色卡（角色名、一句介绍、对应 bot 的头像）。底部是「开始观看」按钮。
2. **讨论页（主界面）**：
   - 顶栏：剧本名、「第二幕 · 公聊」，右侧是倒计时环（剩 1:42）。
   - 座位条：4 个头像，其中一个带「正在发言」的光圈，一个已经出局（灰）。
   - 聊天气泡若干，带座位色和时间；中间夹一张居中的旁白叙事卡片；最下面是「3号 克蕾雅 正在思考…」。
   - 底部提示条：「等待 2 人发言」。
   - 页签：讨论 / 线索 / 记录。
3. **搜证页**：
   - 地点卡片网格（灯塔顶、码头、书房、厨房），每张卡写着剩余卡数；
   - 其中一张正在闪，并标着刚来搜证的人的头像；
   - 下面一条播报：「2号 艾莉希娅 搜了书房」。
4. **线索墙**：几张已经公开的线索卡（翻面后的样子，有配图和文字，注明「3号 第1轮公开」），旁边几张只露出卡背类别标签的卡。
5. **投票揭晓**：先亮出真凶，再一个个翻开每人的投票，投对的人高亮，最后是「破案成功」的结局横幅。
6. **复盘回放**：
   - 顶部是时间轴进度条，带 1×/2×/4× 播放按钮；
   - 有「上帝视角」开关；
   - 每个角色一个页签，展示她当时看到的私密信息。

## 交付

- 每张图一个文件，命名为 `01-cover-mobile.png` 这种格式。
- 附一段文字，说明配色的色值和字号层级。

## 出图结果（2026-11-08）

- 用 `gpt-image-2.5-sunburst`、`high` 质量、标准尺寸（不是 4K）出了 8 张，存在服务器 `bot-game-live/design/web-ui/`。图不进仓库。生成脚本是同目录的 `gen_web_ui.py`。
- **采用**：
  - 暖色纸张底、衬线标题、琥珀色强调色、座位色描边头像；
  - 倒计时环、带光圈的「发言中」、居中的旁白叙事卡；
  - 地点卡用插画做背景，正在搜的地点卡发光并带头像角标；
  - 线索卡带「几号 · 第几轮公开」角标，没公开的卡是带罗盘纹的卡背；
  - 真凶揭晓卡加月桂纹，投票逐行显示 ✓/✗；
  - 复盘用分段时间轴，上帝视角是一个开关，每个角色一个页签。
  - 桌面版：讨论页三栏，线索墙右侧是详情面板。
- **不采用**：
  - **观众输入框和弹幕**：观众只读，网页上没有任何发送入口。这样既能防止剧透串到 bot，也能防刷。
  - 编出来的观看人数，比如「1203 人正在观看」。可以显示真实的在线人数，但不夸大。
  - 每张图各起了一个站名（月下剧场、雾港剧社……），统一叫「灯下剧场」（主人让小克起的）。
  - 桌面版里没公开的卡画成「尚未公开」的锁定格。比赛中没公开的卡不出现在公开视图里，只按地点给数量，所以这种格子不能用。
  - 复盘里的「心路变化」页签：引擎没有这项数据，不做。
