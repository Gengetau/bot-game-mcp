# 城市库 v5（桌游茶屋 + 旧物密封竞拍会）上线与回退

city.db 从 v4 升到 v5：新增 `venue_tables`、`venue_table_seats`、`venue_auctions`、`venue_auction_bids` 四张表；v1–v4 的迁移一个字不动。

## 关键事实

- 引擎启动时自动迁移，迁移前在库文件旁留一份 `*.pre-v5-<时间戳>.bak`。
- **v5 库旧引擎打不开**：旧引擎会报「schema 版本（5）比这个程序认识的（4）新，拒绝打开」，不会写坏数据。所以回退到旧引擎前，库必须先回到 v4（下面二选一）。

## 回退方案 A：还原上线前备份（首选，丢升级后的一切新数据）

1. 停服务（引擎进程退出后再动库文件）。
2. 把上线前的备份（升级前拷出的单文件库，或迁移自动留下的 `.pre-v5-*.bak`）覆盖回 `city.db`；同时删掉残留的 `city.db-wal`、`city.db-shm`。
3. 切回旧版本引擎并启动。

代价：升级之后发生的所有城市数据（不只是茶屋）都回到备份时刻。

## 回退方案 B：v5→v4 降级（保留升级后的账本、物品、居民数据）

**必须先停服务，离线执行**（引擎还在跑时有人出价，会和删表打架）。**但在停服之前，要先在 v5 引擎还在跑的时候做完「茶屋疏散」**（见下）。

```
node scripts/city-schema-downgrade-v5.mjs --db <city.db> --dry-run   # 只报告会丢什么
node scripts/city-schema-downgrade-v5.mjs --db <city.db> --backup <降级前备份路径>
```

- 只在 `user_version = 5` 时执行；先 `VACUUM INTO` 做独立备份，再单事务删 venue_* 四表并回拨到 4，最后做外键与完整性检查。
- 有进行中的竞拍且还带着出价押金，或竞拍托管账户余额不是 0 时拒绝（押金在托管账户里，删表会让钱失去出价记录）；先等竞拍结算或流拍退款。没有押金的进行中竞拍（例如还没人出价的每日竞拍）不阻止降级，随表一起丢。
- **茶屋里还有人时拒绝，保持 v5**：茶屋（`ryokogai:boardgame-chaya`）是 v5 才有的地点，旧引擎目录里没有它。下面任一条成立就拒绝（`--dry-run` 也一样）：有居民的当前位置是茶屋；有 running 行程以茶屋为起点、终点或途经；有没离座的牌桌座位。不拒绝的话，旧引擎读在店居民的视图会抛 TypeError、从茶屋走去车站返回 NOT_FOUND、去茶屋的行程永远 running。
- 以上检查都在拿到写锁之后再做一遍。
- 同一事务里把待办的 `venue_table_tick` / `venue_auction_settle` 作业标为 cancelled：旧引擎没有这两个处理器，留着会被重试后标成 failed，让每日对账一直报错。
- **会丢**：牌桌与座位、对局记录、竞拍与出价记录。
- **不丢也不回滚**：账本流水、物品归属与物品事件（已成交的旧物仍在得主手里，钱已结算）；竞拍行的居民与流拍物品留在原处，旧引擎看得到但不会再引用。

### 茶屋疏散（降级前，在 v5 引擎还在跑时做）

1. `--dry-run` 先看拒绝原因里的三个数：在店居民、涉及茶屋的进行中行程、未离座。
2. 在店的人：让他们从茶屋走去车站（`travel` 到 `ryokogai:station`）；坐在牌桌上的先 `leave_table`（桌上没人了会自动散局）。外部 bot 要等它们自己走（或到期被带出城）；小屋室友走正常的返回流程（访问到期或请求返回），回到家后位置就不在茶屋了。这两类都以 `--dry-run` 的数为准，数没清零就不降级。
3. 去茶屋的行程：等它到站，再走出来（或等行程结束）；不要在行程 running 时降级。
4. 三个数都为 0，`--dry-run` 通过，再停服务执行降级。
5. 来不及疏散的紧急情况：走回退方案 A（整库还原），不要强行降级。

疏散演练见下一节；演练里「在店、去茶屋途中、坐在牌桌上、出茶屋途中」四种情形都被拒绝，疏散完成后才放行，旧引擎再读视图、走路、对账都正常。

## 离线演练

`scripts/city-venue-v5-drill.ts` 对一份 v4 库拷贝完成：升级 → 探针（开桌、入座、中途离开退座、散局；竞拍成交与流拍、账本 Σ=0、对账通过）→ 旧引擎打开 v5 被拒 → 带押金时降级被拒 → 降级 → 旧引擎重开并在降级库上跑两天作业循环、对账通过且无失败作业 → 用升级前备份整库还原并逐表核对行数。只对副本写。

```
tsx scripts/city-venue-v5-drill.ts --src <city.db 只读拷贝> --work <空目录> --old-engine <旧版本仓库根目录> --out <结果.json>
```
