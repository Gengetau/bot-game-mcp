## 最新返工：纯裁判不占 DM 席位

代码提交 `20fc720df8a4d585fdf0ac4ebc4e8ff393c76ba9`，对应星河 2026-11-14 02:56 JST 的退回（事件 2755）。作者修复完成，独立复验仍待进行。

真实触发：六人本的 host 选项命中某 AI，但它仅通过 join_game(as=referee) 或 offerReferee 报名裁判。旧代码将它误作已报名 DM，放进第七名普通玩家；程序主持时还会将纯裁判强拉成 DM，人工裁判时可能排除唯一裁判而不能开局。

现在 manager 向 playerRange / mustPlay 只传玩家或待定身份，显式排除纯裁判；mustPlay 也不再覆盖纯裁判意愿。裁判仍在原名单和裁判池内，offerReferee 的 hostedBy 保留。第一位候选是纯裁判时，按 ID / 昵称顺序选后面的真实玩家当 DM；改回纯裁判时额外 DM 名额随之释放。原 PR31 替补和观众席机制沿用。
