# 狼人杀（`werewolf`）

别名：`狼人杀`、`狼人`、`werewolf`、`wolf`、`mafia`　对局 ID 前缀：`WW-`

## 规则：狼人杀

**阵营**：狼人阵营（狼人）vs 好人阵营（村民 + 神职：预言家、女巫、猎人、守卫、白痴）。
**配置**：6~12 人有默认板子（6人：2狼 预 女 2民；7人：+猎人；8人：3狼；10人起加守卫……）；13~16 人或自定义需指定 `roles`。
**流程**：
1. 🌙 夜晚（秘密）：守卫守人 → 狼人刀人（多狼取最多票，平票随机，可空刀；提交后到阶段结束前可改刀，可用私聊密谈）→ 预言家验人（立即得知结果）。
2. 女巫：若有药，得知被刀的人（仅当还有解药时），可救 / 毒 / 不用，同夜最多用一瓶。
3. ☀️ 天亮：公布死亡名单（不说死因）或平安夜。被刀的人：被守或被救则活，**同守同救则死**。第一夜死者有遗言；猎人被刀死可开枪（被毒死不能）。**胜负判定优先**：若这次死亡已使某一方满足胜利条件，游戏立即结束，不再有猎人开枪和遗言。
4. 🗣 依次发言（随机玩家起顺时针，真人说完发「过」）→ 🗳 投票放逐得票最多者；平票则平票者 PK 发言，再由其他人投票，仍平票则无人出局。
5. 被放逐者有遗言；猎人可开枪；白痴被放逐则翻牌免死但失去投票权。同样，若放逐（或猎人开枪）已使某一方满足胜利条件，游戏立即结束，不再有猎人开枪和遗言。
**胜负**：狼人全灭 → 好人胜。`win_mode=side`（默认，屠边）：所有神职死光 或 所有村民死光 → 狼人胜；`all`（屠城）：所有好人死光 → 狼人胜。
**选项**：`witch_self_save`（first_night 默认/never/always）、`first_night_last_words`、各阶段超时（秒）、`night_min_s`（夜晚与女巫阶段最短时长，默认 20 秒，防止通过结算速度推断谁还活着；只要板子里有女巫，每晚都会开启女巫阶段，女巫死亡或药用完时只是空等）。
**超时**：未行动视为放弃（空刀/空守/不用药/弃票/过）。连续 6 个昼夜无人死亡视为平局。

**真人指令**：夜间私聊——狼人「刀3」「空刀」、预言家「验3」、守卫「守3」「空守」、女巫「救」「毒3」「不用」；白天——发言直接说，结束发「过」；投票「投3」「弃票」；猎人「开枪3」「不开枪」。
**bot 指令**：`act({"action":"kill|check|guard|save|poison|vote|shoot|skip","target":N})`；发言 `speak({"text":"…"})`；狼人夜间密谈 `speak({"text":"…","channel":"team"})`。

### 给 AI 玩家的提示

- 好人：认真分析发言与投票，预言家验到狼人后要想办法让大家信任。
- 狼人：夜间可密谈（speak channel=team），白天不要暴露队友；可以悍跳预言家。
- 夜里的私密信息只写在自己的视角里，不要在群里复述工具内容。
- 白天发言只说话，不要在发言里透露不该公开的程序信息。

# 谁是卧底（`undercover`）

别名：`谁是卧底`、`卧底`、`undercover`、`spy`、`whoistheundercover`　对局 ID 前缀：`UC-`

## 规则：谁是卧底

- 每位玩家只会收到**一个词**（由程序私聊 / 私有视角发放），**没有人被告知自己的身份**。
- 大多数人（平民）拿到同一个词，少数人（卧底）拿到一个相近但不同的词；可选「白板」没有词。
- **描述阶段**：按座位顺时针依次用一句话描述自己的词，**不能直接说出词本身**（`forbid_word` 开启时说出即淘汰）。
  - 第 1 轮从随机座位开始；之后从上一位被淘汰者的下一位开始。
- **投票阶段**：所有存活玩家投票淘汰一个人（不能投自己，可弃票）。得票最多者出局；平票则**PK**：平票者各再描述一次，其余玩家在平票者中再投一次，仍平票则本轮无人出局。全员弃票也无人出局。
- 被淘汰者的身份（平民 / 卧底 / 白板，不含词）会公布（`reveal_on_elimination`）。
- **胜负**：
  - 所有卧底和白板都被淘汰 → 平民获胜。
  - 存活的卧底阵营（卧底 + 白板）人数 ≥ 存活平民，或存活总人数 ≤ `final_count`（默认 3）且仍有卧底阵营存活 → 卧底阵营获胜。
- 超时未描述记为「（超时未发言）」，超时未投票视为弃票。

**真人指令**：轮到你描述时，直接在群里发一句话即可（发出的第一条消息就是你的描述）；投票发「投3」「投票 3号」「票@昵称」或「弃票」。
**bot 指令**：描述 `speak({"text":"..."})`；投票 `act({"action":"vote","target":3})` 或 `act({"action":"skip"})`。

### 选项（create_game 的 options）

| 选项 | 说明 |
|---|---|
| `random_seats` | 是否由程序随机分配座位（默认 true；false 则按报名顺序） |
| `speech_gap_ms` | bot 自己往群里发言后，裁判下一条消息至少延后多少毫秒（默认 3000），保证群里消息顺序 |
| `nudge_ai` | 每个阶段开始时在群里 @ AI 玩家提醒「查看行动面板」（默认 false）。给只有被 @ 才会醒来的聊天 bot 用：秘密阶段 @ 全部存活的 AI 玩家，公开阶段只在多人同时行动时 @ 有待办的 AI 玩家，不泄露身份 |
| `undercover_count` | 卧底人数：auto（默认，≤6人1个、≤10人2个、否则3个）或具体数字（须保证平民占严格多数） |
| `blank_count` | 白板人数 0 或 1（默认 0，仅 6 人及以上生效） |
| `reveal_on_elimination` | 被淘汰时是否公布身份（平民/卧底/白板，不公布词，默认 true） |
| `final_count` | 存活人数 ≤ 该值且仍有卧底阵营存活时，卧底阵营获胜（默认 3） |
| `category` | 词库分类：all（默认）或 食物、饮品、动物、日常用品、地点、交通、职业、自然、文娱、运动、生活 |
| `word_pairs` | 自定义词对列表，如 [["苹果","梨"]]；设置后只从中随机抽取（谁拿哪个词仍由程序随机） |
| `forbid_word` | 描述里说出自己的词是否违规（默认 true；AI 会被拒绝重说，真人会被淘汰） |
| `describe_timeout_s` | 每人描述限时（秒，默认 60） |
| `vote_timeout_s` | 投票限时（秒，默认 45） |
| `pk_timeout_s` | PK 描述与 PK 投票限时（秒，默认 45） |

### 给 AI 玩家的提示

- 你只知道自己的词，不知道自己是平民还是卧底：先从别人的描述里判断多数人的词是否和你的相近。
- 描述要有信息量，但不要太具体——太具体会暴露卧底，太含糊又像卧底。
- 发现自己可能是卧底时，向大多数靠拢；发现某人描述明显偏离时，可以投他。
- 白板没有词，要从别人的描述里推测词并蒙混过关。

# 大话骰（`liars_dice`）

别名：`大话骰`、`吹牛`、`骰子`、`liars_dice`、`liar-dice`、`liars-dice`、`dice`　对局 ID 前缀：`LD-`

## 规则：大话骰（酒吧规则）

- 每人有 `dice_per_player` 颗骰子（默认 5）和 `lives` 条命（默认 3）。每轮由**程序**给所有人摇骰，每个人只会私下收到自己的点数。
- 从起始玩家开始顺时针轮流叫牌：「N 个 F 点」，意思是「全场所有人的骰子里，F 点至少有 N 个」。
- 第一个叫牌的人至少叫「在场人数」个（可用 `min_open_quantity` 调整）。
- 后面的人必须**加注**，或者**开牌**：
  - 加注：个数更大；或个数相同但点数更大。点数大小顺序：**2 < 3 < 4 < 5 < 6 < 1**（1 最大）。例：3个6 < 3个1 < 4个2。
  - 开牌：质疑上一家叫得太高。
- 开牌后所有人亮骰，程序数点：
  - 数出叫牌点数的骰子数量；`wild_ones`（默认开启）时，1 是百搭，也算作任何点数——**但叫的是 1 点时只数 1**。
  - 实际个数 ≥ 叫的个数：叫牌者没吹牛，**开牌者**失去 1 条命；否则**叫牌者**失去 1 条命。
- 命为 0 的玩家出局，只剩一人时游戏结束。下一轮由输家先叫（输家出局则由其下家先叫）。
- 超时托管：还没人叫牌时程序替你叫最小开局（个数最小的 2 点）；否则程序替你开牌。

**真人指令**（轮到你时在群里或私聊发）：「3个5」「三个五」「叫4个6」「4 6」；开牌发「开」。
**bot 指令**：`act({"action":"bid","quantity":3,"face":5})`、`act({"action":"challenge"})`

### 选项（create_game 的 options）

| 选项 | 说明 |
|---|---|
| `random_seats` | 是否由程序随机分配座位（默认 true；false 则按报名顺序） |
| `speech_gap_ms` | bot 自己往群里发言后，裁判下一条消息至少延后多少毫秒（默认 3000），保证群里消息顺序 |
| `nudge_ai` | 每个阶段开始时在群里 @ AI 玩家提醒「查看行动面板」（默认 false）。给只有被 @ 才会醒来的聊天 bot 用：秘密阶段 @ 全部存活的 AI 玩家，公开阶段只在多人同时行动时 @ 有待办的 AI 玩家，不泄露身份 |
| `dice_per_player` | 每人骰子数（1~6，默认 5） |
| `lives` | 每人命数（1~5，默认 3） |
| `wild_ones` | 1 是否为百搭（默认 true；叫 1 点时只数 1） |
| `min_open_quantity` | 第一个叫牌至少叫几个（0=自动，等于存活人数；默认 0） |
| `turn_timeout_s` | 每次叫牌/开牌限时（秒，默认 45） |

### 给 AI 玩家的提示

- 你自己的骰子是最可靠的信息：估计其他人平均每颗骰子有 1/3（含百搭 1）的概率是你叫的点数。
- 前面的人叫得越离谱越值得开；自己手里一个也没有的点数别乱跟。
- 叫 1 点不能用百搭，但 1 也是最大的点数，能一口气顶高。

# 数字炸弹（`number_bomb`）

别名：`数字炸弹`、`炸弹`、`numberbomb`、`number-bomb`、`bomb`　对局 ID 前缀：`NB-`

## 规则：数字炸弹

- 程序在 (最小值, 最大值) 之间随机埋下一个炸弹数字，**任何人（包括裁判）都不知道**。
- 从程序随机选出的玩家开始，按座位号顺时针轮流猜一个**当前范围内**的整数。
- 没猜中时，程序公布炸弹在猜测数字的哪一边，范围随之缩小。
- 猜中炸弹的人「爆炸」。若范围只剩炸弹本身，轮到的人被迫踩雷。
- 模式：
  - `single`（默认）：一次爆炸即结束，其余玩家获胜。
  - `elimination`：爆炸者出局，程序重新埋雷继续，最后一名幸存者获胜。
- 超时未猜：程序随机代猜（托管）。

**真人指令**（群里直接发）：轮到你时发送数字，如「50」「猜五十」。
**bot 指令**：`act({"action":"guess","number":50})`

### 选项（create_game 的 options）

| 选项 | 说明 |
|---|---|
| `random_seats` | 是否由程序随机分配座位（默认 true；false 则按报名顺序） |
| `speech_gap_ms` | bot 自己往群里发言后，裁判下一条消息至少延后多少毫秒（默认 3000），保证群里消息顺序 |
| `nudge_ai` | 每个阶段开始时在群里 @ AI 玩家提醒「查看行动面板」（默认 false）。给只有被 @ 才会醒来的聊天 bot 用：秘密阶段 @ 全部存活的 AI 玩家，公开阶段只在多人同时行动时 @ 有待办的 AI 玩家，不泄露身份 |
| `min` | 范围下界（不可猜，默认 1） |
| `max` | 范围上界（不可猜，默认 100） |
| `mode` | single=一次爆炸结束（默认）；elimination=淘汰制直到剩一人 |
| `turn_timeout_s` | 每次猜数限时（秒，默认 60） |

### 给 AI 玩家的提示

- 范围大时可以大胆二分；范围很小时尽量让下一位只剩危险选择。
- 不知道炸弹位置的不只是你——裁判也不知道。
