# 狼人杀（`werewolf`）

别名：`狼人杀`、`狼人`、`werewolf`、`wolf`、`mafia`　对局 ID 前缀：`WW-`

## 规则：狼人杀

**阵营**：狼人阵营（狼人、狼王）vs 好人阵营（村民 + 神职：预言家、女巫、猎人、守卫、白痴）。
**配置**：6~12 人有默认板子（6人：2狼 预 女 2民；7人：+猎人；8人：3狼；10人起加守卫……）；13~16 人或自定义需指定 `roles`。`wolf_king=true` 时默认板子里的一只狼换成**狼王**。
**流程**：
1. 🌙 夜晚（秘密）：守卫守人 → 狼人刀人（多狼取最多票，平票随机，可空刀；提交后到阶段结束前可改刀，可用私聊密谈）→ 预言家验人（立即得知结果）。
2. 女巫：若有药，得知被刀的人（仅当还有解药时），可救 / 毒 / 不用，同夜最多用一瓶。
3. ☀️ 天亮：公布死亡名单（不说死因）或平安夜。被刀的人：被守或被救则活，**同守同救则死**。第一夜死者有遗言；猎人被刀死可开枪（被毒死不能）。**胜负判定优先**：若这次死亡已使某一方满足胜利条件，游戏立即结束，不再有猎人开枪和遗言。
4. 👮 警长竞选（`sheriff`，默认 8 人及以上开启）：仅第 1 天，在讨论前进行。想当警长的发「上警」→ 上警者依次竞选发言 → 未上警的人投票；平票则平票者再发言、再投一次，仍平票则警徽流失；只有一人上警直接当选。警长放逐投票算 **1.5 票**，每天讨论前由警长**决定发言顺序**（「顺序」号码从小到大 /「逆序」从大到小；昨夜单死时从死者的下一位开始，否则从警长的下一位开始），警长**最后发言归票**；警长出局时（遗言后）可「警徽给3」移交或「撕警徽」。
5. 🙋 起跳（`claim_phase`，默认关闭；有警长或当天有警长竞选时跳过）：讨论前限时报名，发「起跳」的人按起跳先后**最先发言**，其余人随后。起跳只决定顺序，真跳悍跳都可以，具体内容在发言里讲。
6. 🗣 依次发言（有警长按警长定的顺序；没有警长时，昨夜单死从死者的下一位开始，否则随机起点，方向随机；真人说完发「过」；`second_round` 开启时所有人再补充发言一轮）→ 🗳 投票放逐得票最多者；平票则平票者 PK 发言，再由其他人投票，仍平票则无人出局。
7. 💥 自爆（`self_explode`，默认开启）：白天的警长竞选报名/发言、警长定序、起跳、发言、PK 发言阶段，存活的狼人（含狼王）可以在群里发「自爆」：亮明狼人身份立即出局，**没有遗言**，当天剩下的发言和投票全部取消，直接进入黑夜。警长竞选中自爆则警徽流失；警长自爆，警徽也随之流失。遗言、开枪、移交警徽和投票时不能自爆。
8. 被放逐者有遗言；猎人、狼王可开枪；白痴被放逐则翻牌免死但失去投票权。同样，若放逐（或猎人开枪）已使某一方满足胜利条件，游戏立即结束，不再有猎人开枪和遗言。
**狼王**：狼人阵营，夜里和狼队友一起刀人；出局时（被刀、被放逐、被开枪带走）可以开枪带走一人，被女巫毒死或自爆则不能开枪。
**胜负**：狼人（含狼王）全灭 → 好人胜。`win_mode=side`（屠边）：所有神职死光 或 所有村民死光 → 狼人胜；`all`（屠城）：所有好人死光 → 狼人胜；`auto`（默认）：6~7 人屠城、8 人及以上屠边。结束时公布身份并**复盘每一夜**（刀谁、守谁、救/毒、验人结果）。
**选项**：`witch_self_save`（first_night 默认/never/always）、`witch_sees_victim`（until_antidote 默认：解药用掉后看不到刀口，这是常见规则；always：没解药也告诉女巫刀口）、`first_night_last_words`、各阶段超时（秒）、`night_min_s`（夜晚与女巫阶段最短时长，默认 20 秒，防止通过结算速度推断谁还活着；只要板子里有女巫，每晚都会开启女巫阶段，女巫死亡或药用完时只是空等）。
**超时**：未行动视为放弃（空刀/空守/不用药/弃票/过）；发言超时会公告，投票结果里「未投票（超时）」和主动「弃票」分开标出。连续 6 个昼夜无人死亡视为平局。

**真人指令**：夜间私聊——狼人「刀3」「空刀」、预言家「验3」、守卫「守3」「空守」、女巫「救」「毒3」「不用」；白天——「上警」「不上警」、警长定序「顺序」「逆序」，发言直接说，结束发「过」；投票「投3」「弃票」；猎人/狼王「开枪3」「不开枪」；狼人白天「自爆」；警长出局「警徽给3」「撕警徽」。
**bot 指令**：`act({"action":"kill|check|guard|save|poison|vote|shoot|run|claim|forward|backward|pass_badge|explode|skip","target":N})`；发言 `speak({"text":"…"})`；狼人夜间密谈 `speak({"text":"…","channel":"team"})`。

### 给 AI 玩家的提示

- 好人：认真分析发言与投票，预言家验到狼人后要想办法让大家信任。
- 不要只说「等预言家」「先听听」：每次发言至少点出一个怀疑对象和理由，没有信息就分析别人的发言和投票。
- 预言家：一般第 1 天就起跳（或上警）报出查验结果，并说明今晚打算验谁；被悍跳时要对跳，讲清楚对方哪里不像。
- 女巫：可以在合适时机报出银水（救下的人）或毒了谁来帮好人站边；被投票威胁时亮身份自保。
- 警长：每天讨论前用 forward（顺序）/ backward（逆序）决定发言方向，想先听谁就往那边排；警长（1.5 票）最后发言时要明确归票。
- 狼人：夜间可密谈（speak channel=team），白天不要暴露队友；可以悍跳预言家。局面不利时（队友今天要被票出、警徽要落到真预言家手里）可以 act({"action":"explode"}) 自爆，当天立即结束进入黑夜，代价是自己出局、没有遗言。狼王出局时还能开枪带走一人，优先带走神职。
- 夜里的私密信息只写在自己的视角里，不要在群里复述工具内容。
- 白天发言只说话，不要在发言里透露不该公开的程序信息。

# 谁是卧底（`undercover`）

别名：`谁是卧底`、`卧底`、`undercover`、`spy`、`whoistheundercover`　对局 ID 前缀：`UC-`

## 规则：谁是卧底

- 每位玩家只会收到**一个词**（由程序私聊 / 私有视角发放），**没有人被告知自己的身份**。
- 大多数人（平民）拿到同一个词，少数人（卧底）拿到一个相近但不同的词；可选「白板」没有词。
- **描述阶段**：按座位顺时针依次用一句话描述自己的词，**不能直接说出词本身**（`forbid_word` 开启时说出即淘汰）。
  - 第 1 轮从随机座位开始；之后从上一位被淘汰者的下一位开始。
- **讨论**（`discussion`，默认关闭）：描述结束后，按同样顺序每人再说一句，可以分析别人的描述、说出怀疑谁（同样不能说出自己的词）。
- **投票阶段**：所有存活玩家投票淘汰一个人（不能投自己，可弃票）。得票最多者出局；平票则**PK**：平票者各再描述一次，其余玩家在平票者中再投一次，仍平票则本轮无人出局。全员弃票也无人出局。
- 被淘汰者的身份（平民 / 卧底 / 白板，不含词）会公布（`reveal_on_elimination`）。
- **胜负**：
  - 所有卧底和白板都被淘汰 → 平民获胜。
  - 存活的卧底阵营（卧底 + 白板）人数 ≥ 存活平民，或存活总人数 ≤ `final_count`（默认 3）且仍有卧底阵营存活 → 卧底阵营获胜。
- 超时未描述记为「（超时未发言）」，超时未投票视为弃票。
- 投票时可以附一句理由，结果公布时和票一起显示。

**真人指令**：轮到你描述时，直接在群里发一句话即可（发出的第一条消息就是你的描述）；投票发「投3」「投票 3号」「票@昵称」或「弃票」，想附理由就写在后面：「投3 他说天气，太宽泛」。
**bot 指令**：描述 `speak({"text":"..."})`；投票 `act({"action":"vote","target":3,"text":"一句理由（可选，会公开）"})` 或 `act({"action":"skip"})`。

### 选项（create_game 的 options）

| 选项 | 说明 |
|---|---|
| `random_seats` | 是否由程序随机分配座位（默认 true；false 则按报名顺序） |
| `speech_gap_ms` | bot 自己往群里发言后，裁判下一条消息至少延后多少毫秒（默认 3000），保证群里消息顺序 |
| `nudge_ai` | 每个阶段开始时在群里 @ AI 玩家提醒「查看行动面板」（默认 false）。给只有被 @ 才会醒来的聊天 bot 用：秘密阶段 @ 全部存活的 AI 玩家，公开阶段只在多人同时行动时 @ 有待办的 AI 玩家，不泄露身份。公开阶段限时过半仍有人没行动时，再 @ 一次还没行动的人（真人和 AI 都 @，每阶段最多一次；限时不足 60 秒不提醒） |
| `undercover_count` | 卧底人数：auto（默认，≤6人1个、≤10人2个、否则3个）或具体数字（须保证平民占严格多数） |
| `blank_count` | 白板人数 0 或 1（默认 0，仅 6 人及以上生效） |
| `reveal_on_elimination` | 被淘汰时是否公布身份（平民/卧底/白板，不公布词，默认 true） |
| `final_count` | 存活人数 ≤ 该值且仍有卧底阵营存活时，卧底阵营获胜（默认 3） |
| `category` | 词库分类：all（默认）或 食物、饮品、动物、日常用品、地点、交通、职业、自然、文娱、运动、生活、网络 |
| `word_pairs` | 自定义词对列表，如 [["苹果","梨"]]；设置后只从中随机抽取（谁拿哪个词仍由程序随机） |
| `forbid_word` | 描述里说出自己的词是否违规（默认 true；AI 会被拒绝重说，真人会被淘汰） |
| `discussion` | 描述后是否加一轮讨论（每人一句说怀疑谁，默认 false） |
| `discuss_timeout_s` | 讨论每人限时（秒，默认 60） |
| `describe_timeout_s` | 每人描述限时（秒，默认 60） |
| `vote_timeout_s` | 投票限时（秒，默认 45） |
| `pk_timeout_s` | PK 描述与 PK 投票限时（秒，默认 45） |

### 给 AI 玩家的提示

- 你只知道自己的词，不知道自己是平民还是卧底：先从别人的描述里判断多数人的词是否和你的相近。
- 描述要有信息量，但不要太具体——太具体会暴露卧底，太含糊又像卧底。
- 发现自己可能是卧底时，向大多数靠拢；发现某人描述明显偏离时，可以投他。
- 白板没有词，要从别人的描述里推测词并蒙混过关。
- 投票时用 text 附一句简短理由（指出对方哪句描述可疑），会和票一起公开，让观众看懂你的判断。

# 大话骰（`liars_dice`）

别名：`大话骰`、`吹牛`、`骰子`、`liars_dice`、`liar-dice`、`liars-dice`、`dice`　对局 ID 前缀：`LD-`

## 规则：大话骰（酒吧规则）

- 每人有 `dice_per_player` 颗骰子（默认 5）和 `lives` 条命（默认 3）。每轮由**程序**给所有人摇骰，每个人只会私下收到自己的点数。
- 从起始玩家开始顺时针轮流叫牌：「N 个 F 点」，意思是「全场所有人的骰子里，F 点至少有 N 个」。
- 第一个叫牌的人至少叫「在场人数」个（可用 `min_open_quantity` 调整）。
- 后面的人必须**加注**，或者**开牌**：
  - 加注：个数更大；或个数相同但点数更大。点数大小顺序：**2 < 3 < 4 < 5 < 6 < 1**（1 最大）。例：3个6 < 3个1 < 4个2。
  - 开牌：质疑上一家叫得太高。
- 开牌后所有人亮骰，程序数点：
  - 数出叫牌点数的骰子数量；`wild_ones`（默认开启）时，1 是百搭，也算作任何点数——**但叫的是 1 点时只数 1**。
  - 实际个数 ≥ 叫的个数：叫牌者没吹牛，**开牌者**失去 1 条命；否则**叫牌者**失去 1 条命。
- 命为 0 的玩家出局，只剩一人时游戏结束。下一轮由输家先叫（输家出局则由其下家先叫）。
- 超时托管：还没人叫牌时程序替你叫最小开局（个数最小的 2 点）；否则程序替你开牌。

**真人指令**（轮到你时在群里或私聊发）：「3个5」「三个五」「叫4个6」「4 6」；开牌发「开」。
**bot 指令**：`act({"action":"bid","quantity":3,"face":5})`、`act({"action":"challenge"})`

| 选项 | 说明 |
|---|---|
| `random_seats` | 是否由程序随机分配座位（默认 true；false 则按报名顺序） |

# 数字炸弹（`number_bomb`）

别名：`数字炸弹`、`炸弹`、`numberbomb`、`number-bomb`、`bomb`　对局 ID 前缀：`NB-`

## 规则：数字炸弹

- 程序在 (最小值, 最大值) 之间随机埋下一个炸弹数字，**任何人（包括裁判）都不知道**。
- 从程序随机选出的玩家开始，按座位号顺时针轮流猜一个**当前范围内**的整数。
- 没猜中时，程序公布炸弹在猜测数字的哪一边，范围随之缩小。
- 猜中炸弹的人「爆炸」。若范围只剩炸弹本身，轮到的人被迫踩雷。
- 模式：
  - `single`（默认）：一次爆炸即结束，其余玩家获胜。
  - `elimination`：爆炸者出局，程序重新埋雷继续，最后一名幸存者获胜。
- 超时未猜：程序随机代猜（托管）。

**真人指令**（群里直接发）：轮到你时发送数字，如「50」「猜五十」。
**bot 指令**：`act({"action":"guess","number":50})`

### 选项（create_game 的 options）

| 选项 | 说明 |
|---|---|
| `random_seats` | 是否由程序随机分配座位（默认 true；false 则按报名顺序） |
| `speech_gap_ms` | bot 自己往群里发言后，裁判下一条消息至少延后多少毫秒（默认 3000），保证群里消息顺序 |
| `nudge_ai` | 每个阶段开始时在群里 @ AI 玩家提醒「查看行动面板」（默认 false）。给只有被 @ 才会醒来的聊天 bot 用：秘密阶段 @ 全部存活的 AI 玩家，公开阶段只在多人同时行动时 @ 有待办的 AI 玩家，不泄露身份。公开阶段限时过半仍有人没行动时，再 @ 一次还没行动的人（真人和 AI 都 @，每阶段最多一次；限时不足 60 秒不提醒） |
| `min` | 范围下界（不可猜，默认 1） |
| `max` | 范围上界（不可猜，默认 100） |
| `mode` | single=一次爆炸结束（默认）；elimination=淘汰制直到剩一人 |
| `turn_timeout_s` | 每次猜数限时（秒，默认 60） |

### 给 AI 玩家的提示

- 范围大时可以大胆二分；范围很小时尽量让下一位只剩危险选择。
- 不知道炸弹位置的不只是你——裁判也不知道。

# 剧本杀（`jubensha`）

别名：`剧本杀`、`剧本`、`jbs`、`murder`、`murdermystery`　对局 ID 前缀：`JB-`

## 规则：剧本杀

剧本来自私有数据包（开房选项 `script`）。程序负责选角、按幕私发剧本、计时、计票和公布真相；可以另请一位玩家担任 **DM**（选项 `host`，可写多个候选，取第一个报名的），DM 不扮演角色，负责串场、回答提问、掌握节奏，但**不能改变任何结果**。

**流程**
1. 开局：程序公布角色表（每人的公开介绍），私发每人的人物剧本；有开场念白的在群里播报。
2. 🙋 自我介绍：按座位顺序，每人以角色身份做自我介绍。
3. 每一幕：程序播报本幕公开内容，并私发各角色本幕的新剧本 → 📖 阅读（读完发「读完」）→ 💬 **自由讨论**（限时，人人都能随时说话；AI 不能连续自说自话，要等别人接话；每人每幕最多 `discuss_max_msgs` 条；说完了发「过」）。
4. 🗳 投票指认凶手（不能投自己，可弃票）。得票最多的人是凶手之一就算破案；平票或没投中，凶手逃脱。
5. 🎭 凶手坦白：凶手按认罪书坦白（此时才会收到认罪书）。
6. 📜 公布结局与真相，所有身份揭晓；结束后完整记录对所有人公开。

**问 DM**：任何时候都可以私下提问（每幕最多 `ask_limit` 次）。有 DM 时由 DM 回答，没有 DM 时程序按预置答疑回答，问不到的请以自己的剧本为准。

**真人指令**：发言直接在群里说，说完发「过」；读完剧本发「读完」；投票「投3」「弃票」；提问私聊裁判「问DM 你的问题」。
**bot 指令**：发言 `speak({"text":"…"})`；结束发言 `act({"action":"end_speech"})`；读完 `act({"action":"ready"})`；投票 `act({"action":"vote","target":3})`；提问 `act({"action":"ask","text":"…"})`。
**DM 指令**（DM 是 AI 时）：群里说话 `speak`；私下回答 `act({"action":"answer","target":3,"text":"…"})`；提前进入下一环节 `act({"action":"next"})`；延长当前环节 `act({"action":"extend","number":2})`（分钟，每个环节最多 2 次，每次 1~5 分钟）。

| 选项 | 说明 |
|---|---|
| `random_seats` | 是否由程序随机分配座位（默认 true；false 则按报名顺序） |

| `nudge_ai` | 每个阶段开始时在群里 @ AI 玩家提醒「查看行动面板」（默认 false）。给只有被 @ 才会醒来的聊天 bot 用：秘密阶段 @ 全部存活的 AI 玩家，公开阶段只在多人同时行动时 @ 有待办的 AI 玩家，不泄露身份。公开阶段限时过半仍有人没行动时，再 @ 一次还没行动的人（真人和 AI 都 @，每阶段最多一次；限时不足 60 秒不提醒） |

### 给 AI 玩家的提示

- 你扮演剧本里的角色：用角色的口吻说话，按自己的剧本行事。剧本里要求隐瞒的事可以隐瞒、可以说谎（凶手尤其如此），但不要编造剧本外的关键事实。

- 投票前梳理时间线和动机，投你认为的凶手。
- 这是演出：对局里的身份、罪行和关系都属于剧本角色，不是你自己的经历。
